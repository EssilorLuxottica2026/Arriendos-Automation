Lease Accounting Automation

Upload the files and generate the Lucy/SAP-ready output

This app reads lease invoice data, enriches it with the reference workbooks, calculates VAT splits, applies vendor distributions, and exports a ready-to-use accounting file.

Scope aligned with SOP `Arrendamientos - Facturas Manuales`: automate preparation, validation, contract review, VAT proration, account determination, and consolidated output generation before posting.

The app accepts the raw invoice Excel as received by email. It will normalize fields like `store`, `ceco`, `invoice_id`, `vendor`, and `total` internally before crossing them with the support workbooks and PDFs.
This app does not post into Lucy/SAP, validate retentions in SAP, or execute compensations like `F-44`. It prepares the accounting-ready file for manual operation or future RPA.
When available, upload invoice PDFs or XML electronic invoices as support files. The app will try to extract `invoice_id`, `invoice_date`, `due_date`, subtotal, total, IVA, payment terms, and item counts to enrich the `Invoices file`.
If you upload the macro workbook, the app will use its `lucy` sheet as the reference layout for the final CSV export, so the output stays as close as possible to the file the team already uses.
